# Data Architect Studio sample

A dependency-free WPF desktop sample for Windows 11, built with .NET 10. It demonstrates an ERwin-inspired data-modeling workspace with a model explorer, entity diagram, properties editor, zoom controls, validation, and DDL generation.

## Run

```powershell
dotnet run
```

## Build a Release executable

```powershell
dotnet build -c Release
```

The output is written to `bin\Release\net10.0-windows\`.
